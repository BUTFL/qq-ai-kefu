# 客服控制台 · 设计规格书（交付开发用）

> 目的：另一个 agent/前端照本文从零实现 **qq-ai-kefu 知识库管理控制台**。
> 配套高保真原型：[console-design.html](console-design.html)（可直接浏览器打开、点击切换各页，本文的视觉基准）。
> 页面清单、字段、语义均对齐真实后端（`bot/admin_web.py` + 原 `napcat-webui-frontend` 的 `config/site.tsx`、`controllers/kb_manager.ts`）。

## 1. 目标与范围

一个**独立**的管理后台（SPA），脱离 NapCat WebUI，直接对接 `bot` 的后端接口（默认 `http://127.0.0.1:8090`，经 `lan` 可局域网）。用于人工维护知识库、审草稿、管名单、发公告。**机器人在群里的答问/审批不经过它**，它只是管理面。

## 2. 技术与对接

- 前端：任意现代框架（原实现是 React + HeroUI + Vite；可自选，但要还原下方视觉）。单页、路由见第 4 节。
- 后端：bot 的 HTTP API，`/api/*`（具体端点读 `bot/admin_web.py` 的路由；数据模型读原 `controllers/kb_manager.ts`：标准答案、草稿、截图学答、爬取、自己人、被封禁、群公告七组）。
- 鉴权：登录页输入 `ADMIN_PASSWORD`（`.env`）。后端 `bot/napcat_auth.py` 需改成校验本地密码并发一个会话 token，前端后续请求带 `Authorization: Bearer <token>`。**不要再依赖 NapCat 的 `/api/auth/check`**。
- 顶栏实时显示**协议端在线状态**（调协议端或 bot 的状态接口）。

## 4. 全局框架

三栏：**左侧栏 232px（深色）｜ 顶栏 ｜ 内容区**。

- **侧栏**：顶部品牌「🛎️ qq-ai-kefu」；导航（图标+文字，选中=品牌色实底白字）：
  `📊 概览 / ✅ 标准答案 / 📚 资料库 / 🕸️ 爬常见问题 / 🖼️ 截图学答法 / 📝 待审草稿(带红色数字角标) / 🤝 自己人 / ⛔ 被封禁的人 / 📢 群公告`
  （顺序与标签对齐真实 `site.tsx`）；底部一行小字：协议端类型 + 版本。
- **顶栏**：当前页标题 + 右侧「● 协议端在线」绿色药丸 + 账号头像/超管/退出。
- **内容区**：浅灰底，卡片承载。

路由：`/login /（概览）/kb/entries /kb/docs /kb/crawl /kb/learn /kb/drafts /kb/trusted /kb/banned /kb/notice`。

## 5. 逐页规格

### 5.0 登录 `/login`
居中卡片：logo + 标题「qq-ai-kefu 客服控制台」+ 说明「输入管理密码（.env 的 ADMIN_PASSWORD）」+ 密码输入框 + 登录按钮。错误时红字提示。

### 5.1 概览 `/`
- 四张统计卡：**标准答案 N 条｜资料块 N 块/M 份｜今日问答 N 次｜待审草稿 N 条**（待审用危险色）。
- 「最近问答」表：问题 / 命中（标签：标准答案·资料命中·未命中）/ 群 / 时间。右上角小字：命中线 0.78 · 资料线 0.49（阈值，来自后端配置）。

### 5.2 标准答案 `/kb/entries`
- 顶部：计数 + 搜索框（问题/答案关键词）+「+ 新增」。
- 表：**问题关键词 / 答案（截断）/ 来源 / 操作**。来源标签三类：`知识库.md`(蓝) `群内定`(青) `复盘采纳`(橙)。操作：编辑、删除。
- 新增/编辑用弹窗（问题、答案、可选附图）。

### 5.3 资料库 `/kb/docs`
- 顶部：「N 份 · M 块」+「↻ 重新入库」+「+ 上传资料」。
- 卡片网格：每份资料一张卡（图标+文件名、块数、更新日期）。点卡进详情/预览。

### 5.4 爬常见问题 `/kb/crawl`
- 顶部：「+ 添加来源」。
- 表：来源 URL / 上次抓取 / 条数 / 操作（立即抓取、移除）。

### 5.5 截图学答法 `/kb/learn`
- 大号拖拽上传区：「把聊天截图拖到这里，或点击上传」+ 说明「抽成对话 → 进待审草稿，采纳才生效」。
- 上传后展示识别出的对话，确认后生成草稿。

### 5.6 待审草稿 `/kb/drafts`
- 夜间复盘起草的问答，逐条卡：Q / A（可编辑）+「采纳 / 驳回」。顶部「全部驳回」。采纳后入标准答案。

### 5.7 自己人 `/kb/trusted`（⚠️语义要准）
- **语义**：名单里的 QQ 号在群里回客户的话，夜间复盘会把它当「人工客服的答法」学成标准答案；不在名单的（客户互答）只当问题。超管 + `.env` 的 `TRUSTED` 固定在最上、**不可改**；页面加的 30 秒内生效。
- 表：QQ 号 / 备注 / 来源（`固定·.env`不可删 vs `手动添加`可删）/ 操作（移除）。顶部「+ 加自己人」（QQ 号 + 备注）。

### 5.8 被封禁的人 `/kb/banned`（⚠️语义要准）
- **语义**：超管踢出群的人自动记入，之后他申请**任何群都自动拒**（回「请输入正确订单号」，不告知、不私聊）。可手动封、解封（踢错了）。
- 表：QQ 号 / 备注 / 来源（`被踢`·`手动加的`·`旧日志导入`）/ 在哪个群被踢（手动的为「—」）/ 操作（解封）。顶部「+ 手动封号」。

### 5.9 群公告 `/kb/notice`
- 选群（多选 chips）+ 公告内容（textarea）+「@全体」开关 +「传群文件」+「发布公告」。
- 下方「已发公告」列表（群、内容、时间、删除）。
- 提示条：@全体 每群每天有次数上限；群公告建议管理员本人发，避免机器人号频繁操作。

## 6. 交互与状态
- 每页有 加载中 / 空列表 / 出错（区分「连不上后端」与「未登录」）三态。
- 删除/解封/驳回/发公告等**破坏性或外发操作**要二次确认弹窗。
- 保存后 toast 提示；列表就地刷新。

## 7. 响应式 / 无障碍
- ≥1100px 三栏；窄屏侧栏可收起为图标。
- 可键盘操作、对比度达 WCAG AA、表格有表头语义。
