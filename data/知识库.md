## 142. 各种报错码怎么处理（401 / 403 / 404 / 429 / 5xx）
**也这么问：** 401 怎么办 / 403 是什么错 / 404 报错 / 429 限流 / 503 no available accounts / 502 是什么问题 / 报错码速查 / stream disconnected before completion / invalid signature in thinking block

401：Key 缺失、无效或被禁用；Base URL 和协议不匹配；改了配置但工具没重启 —— 核对 Key 和 Base URL，重启工具。
402：余额不足 —— 充值或减少用量。403：分组没开相应权限（比如图片生成），或余额、订阅资格不足 —— 先看余额和订阅状态。
404：OpenAI 协议地址漏了 /v1，或 Anthropic 协议地址多写了 /v1，或当前分组不支持这个接口 —— 按接入协议核对 Base URL。
429：当日额度用完，或并发、RPM、上游额度受限 —— 额度用完看常见问题，限流就退避后重试。
500/502/503/504：内部错误、上游暂时失败、没有可用上游账号、超时 —— 有限次数重试；503 还要检查环境变量是否覆盖了 Key。

可以重试：429、502、503、504，以及网络中断、连接重置、读取超时，用指数退避重试 2～3 次。不要重试：400、401 以及余额、权限、参数错误，先改请求。
几个高频原文：401 Unauthorized: Incorrect API key provided = 请求还在走官方接口没走灵眸；503 No available accounts = Shell 环境变量覆盖了工具里的 Key；stream disconnected before completion = 断流，通常是代理或 VPN 换了出口 IP；400 Invalid signature in thinking block = 同一对话里跨分组切换了模型。
求助时附响应头里的请求 ID 和完整报错，别贴完整 API Key。社区原帖：https://community.lmuai.ai/t/44
